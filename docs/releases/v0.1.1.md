# v0.1.1 — Security fixes and dark dashboard

A patch release of LLM Eval Control Plane. It closes newly published
vulnerabilities in the audit and lint toolchains, updates locked dependencies,
and ships the redesigned dashboard. The supported workflows and boundaries from
[v0.1.0](v0.1.0.md) are unchanged.

## What changed

- **Security floors.** The locked audit toolchain now requires `filelock` 4.2.1
  (CVE-2026-112907, CVE-2026-112913, CVE-2026-112940) and `msgpack` 1.2.3
  (CVE-2026-114613), and the dashboard lint toolchain requires `zod` 4.6.6
  (GHSA-mrhx-c7xc-m3w5). These packages are development tooling; they are not
  in the runtime image or the static demo. The weekly dependency audit passes
  again on the locked environment.
- **Dependency updates.** FastAPI 0.162.0, SQLAlchemy 2.1.6, Alembic 1.20.1,
  Ruff 0.17.3, sqlglot 30.25.0, Next.js 16.4.3, Vite 8.3.5, the `astral-sh/uv`
  0.13.6 container base image, and the pinned CodeQL and `setup-uv` Actions.
- **Dark dashboard.** A single dark visual system replaces the layered light
  theme: black canvas, charcoal cards, top pill navigation, segmented slice
  filters, and one violet accent with pass and fail colors kept for status.
  Phone-width clipping in the distribution table and panel counts is fixed.
  Components, class names, and data handling are unchanged.
- **Short demo address.** The public demo is served at
  <https://evalcontrol.vercel.app/>; the original
  `llm-eval-control-plane-idevelopai.vercel.app` domain still works.
- **CI robustness.** The deployment-hardening test gives slow runners more time
  to probe Docker Compose.

## Upgrading

There are no API contract, database schema, migration, CLI, or configuration
changes. Existing deployments keep their project ID, credential registry, and
database. Refresh local environments from the lockfiles:

```bash
uv sync --locked
pnpm --dir dashboard install --frozen-lockfile
```

Rebuild the container image to pick up the new base image.

## Verification and distribution

The release is tagged from reviewed `main` after the required test and security
checks pass, including the Python matrix, PostgreSQL/recovery checks, dashboard
build, dependency audits, secret scanning, container scanning, and CodeQL.

GitHub's source archives contain tracked source and public synthetic fixtures.
No credentials, local evidence, diagnostic notes, backups, or private environment
files are release assets. This release does not publish to PyPI or deploy a
backend. The Python package/CLI version is `0.1.1`; the independently versioned
API contract and artifact schemas are unchanged.
